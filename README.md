# TravelTrust

TravelTrust is a trust-based travel safety platform built on Salesforce.
It connects travelers who face language or navigation barriers with verified helpers
traveling on the same journey.

## Problem
Many travelers struggle due to language barriers, unfamiliar airport procedures,
and lack of reliable human assistance during international travel.

## Solution
TravelTrust enables:
- Same-journey traveler ↔ helper matching
- Verified helpers and safety-first design
- Journey mode with checkpoints and emergency handling
- Admin monitoring and audit controls

## Tech Stack
- Salesforce Experience Cloud
- Apex, LWC, Flows
- Salesforce DX
- GitHub + CI/CD
- Jira & Confluence (Agile SDLC)
